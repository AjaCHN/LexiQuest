4组件使用规则

规则说明
语义化 id所有可交互元素、主要容器加 kebab-case 语义 id（如 #settingsBtn、#today-panel），便于脚本定位与无障碍。
触控目标按钮 / 选项 / 图标按钮最小高度 44px（小号 38px），间距充足，避免误触。
双主题所有颜色走 CSS 变量（var(--*)）；深色态由 html.dark 切换，组件无需改色。
状态反馈操作后用 Toast 反馈；表单错误用 .err + aria-invalid；加载用 .syncing 状态点。
动效克制翻转、淡入、抽屉滑入等动效 ≤0.5s；尊重 prefers-reduced-motion。
真实数据业务组件默认绑定 lib/words.ts 真实词库，原型用节选数据，不得编造字段。
可访问性表单控件关联 label；图标按钮带 title/aria-label；切换类用 role="switch"。
响应式桌面用 Header + Tabs；移动端（≤760px）Tabs 降级为 BottomNav，栅格单列。
