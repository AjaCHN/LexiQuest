# 项目规格 · 英语闯关台 LexiQuest（lexiquest）

> 本文由 PM 整理，作为开发任务拆解的权威依据。所有需求均来自现有实现与既有文档（README / overview / REVIEW），不额外添加规格外的高级诉求。

## 1. 产品定位

为**不同年龄段人群**定制的网页版英语学习工作台。核心学习法是「词素拆分记忆 + 组词练习 + 闯关积分」，纯前端、离线优先，可一键部署到腾讯云 EdgeOne Pages，并通过 Edge KV 实现跨设备云端同步（无登录）。

- 中文名：英语闯关台
- 英文名：LexiQuest
- 仓库/包名：`lexiquest`

## 2. 原始功能需求（摘录自 README/overview）

- **三档年龄段**：儿童启蒙（6-12）/ 青少年学生（13-22）/ 成人进阶（22+），各自独立词库与难度。
- **每日单词**：每天自动安排若干单词，昨天没做完的自动顺延到今天并标红「逾期」。
- **拆分记忆卡**：每张卡片把单词拆成 前缀 / 词根 / 后缀 / 基础词，颜色区分 + 含义提示，点击翻面查看，附朗读。
- **组词练习**：基于同一词根/基础词做多选组词，答对得积分，附带解析。
- **闯关积分**：完成单词 +10、组词 +20、连续打卡累计积分，6 级段位看板。
- **云端同步**：各设备填同一个「同步码」即可跨设备共享进度（Edge KV，无需登录）。
- **数据安全**：本地 localStorage 离线可用 + JSON 导出/导入备份 + 清空二次确认。
- **响应式**：PC 多列、手机单列 + 底部 Tab，支持深色模式，可「添加到主屏幕」当 App。

## 3. 技术栈（来自规格）

- 框架：**Next.js 14（App Router + TypeScript）**
- 样式：**纯 CSS（零外部依赖，内联 SVG 图标）**
- 部署：**腾讯云 EdgeOne Pages**
- 云端存储：**Edge KV**（绑定变量名 `my_kv`）
- 语音：Web Speech API（可选降级）
- 无后端、无数据库、无第三方 UI 框架

## 4. 目标与约束

- 目标：开箱即用、零配置本地运行；部署后无需登录即可跨设备同步。
- 约束：不引入任何外部 CDN / 框架 / 字体；所有写操作先落 localStorage 再更状态。
- 范围边界：当前为 v1.0.0 初版，云端同步为「无登录 + 同步码即密钥」的轻量设计，已知安全与并发问题（见 REVIEW.md）属后续加固项，不在初版阻塞范围。

## 6. 验收基线

- `npm run build` 通过、类型检查无误、SSR 首屏无白屏。
- 三档人群均可用、今日计划可见、积分与段位正确累加。
- 未绑 KV 时降级本地模式；绑 KV 后可按同步码跨设备共享。
